HOW TO USE
Train -> tap a programme session or Preview.
- Tap any exercise row for its detailed reference page.
- Tap 90 min or Edit plan to use the existing training-plan builder.
- Tap Strength calibration to see current exercise load confidence.

During workout:
- Enter reps and kg on the highlighted NEXT set row.
- Tap Log set. The next row inherits those values.
- Change the inherited values only when performance changes.
- Rest starts after a logged set.
- History shows the previous comparable exposure.
- Replace creates a temporary substitution for this workout.
- More opens setup, movement path and grip guidance.
- Add set extends the target for the current exercise.
- Finish workout opens the existing Hercules coaching review.
