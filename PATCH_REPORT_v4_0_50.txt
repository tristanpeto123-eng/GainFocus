HOW TO USE

WORKOUT TIME
Train -> Daily workout availability -> choose a time.
Example: choose "1 hr 30". Each workout preview and Today's workout immediately show how many planned exercises fit.
Preview a specific workout to make a one-off time change.

RECENT WORKOUTS / PROGRAMME
Train -> Recent workouts is directly below Today's workout.
Tap "Your programme" to expand all sessions.

NUTRITION SEARCH
Nutrition -> Log food -> Manual entry -> Search nutrition data.
Type a food/menu item and tap Search data.
The app uses the Region saved in onboarding/profile.
Tap Use on a result to fill Calories/Protein/Carbs/Fat, then Add to today.
"Search wider web" opens a region-specific web search if structured data is unavailable.

REGION
Account -> Edit profile -> Region.
New users also choose Region during onboarding.

NOTIFICATIONS
Hercules Home -> bell in the top header.
Notification feed + notification controls are in this screen.

CHECK-IN
Check-in -> the top card now contains both the check-in form and Hercules snapshot.
Body composition, latest analysis and history remain collapsible underneath.

ANALYSIS TRAJECTORY
Analysis -> Trending statistics -> Weight.
The dashed planned trajectory starts at the plan's start weight/date and ends at the goal weight/date.

NOTE
Open Food Facts provides online structured packaged-food data. Restaurant/menu items can vary by country and over time; the app records the lookup region/source when an online result is used.
